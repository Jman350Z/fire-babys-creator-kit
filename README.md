# 🔥 Fire Babys Creator Kit

## Build a game mode. Win $10,000.

Welcome, creator. This is the official starter kit for the **Fire Babys Creator Competition**.

**The deal:** design an original game mode for Fire Babys. Thousands will build. One ships in the official phone app — and its creator gets **$10,000**.

## Start here

1. Read **[STARTER-PROMPT.md](STARTER-PROMPT.md)** — your creative brief. Follow it exactly.
2. Read **[COMPETITION-RULES.md](COMPETITION-RULES.md)** — the prize, the terms, how to submit.
3. Build your game mode (one HTML file preferred, or a Godot 4 project).
4. Submit it for review.

## The 6 Pillars (your game MUST follow all six)

1. **Synthesized Web Audio** — all sound generated in code. No audio files.
2. **Plushie silhouettes** — round, soft flame-teardrops. Zero beaks, wings, or feathers. Ever.
3. **Slapstick, not violence** — Fall Guys energy. Nobody gets hurt. Fire Babys are precious.
4. **NFPA matchup engine** — fire classes (A/B/C/D) beaten by the right tools, like real firefighters do it.
5. **Under 250KB** — loads instantly on a cheap phone. No bloat.
6. **Real curriculum** — the lesson comes from USFA/NFPA guidance (get low and go, get out/stay out, call 911, test alarms, two ways out, stop-drop-and-roll).
